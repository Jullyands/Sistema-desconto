# Sistema de desconto
## Autor: Anna Jullya

Este projeto em python foi feito para praticar os comandos **if**,**else** e **elif**. O programa solicita o **valor** da compra e entrega o valor total a ser pago com o desconto.

O comando **print** aparece para responder o valor do desconto e o total, sendo calculado por **total**, o qual multiplica o valor solicitado pela subtração de 1,00 pelo desconto em número decimal.

O comando **if** é utilizado para estabelecer o que ocorre com valores abaixo de 200, o comando **elif** é utilizado para igual ou os que estão acima de 300, enquanto o comando **else** determina o cálculo a partir dos valores que estão entre 200 e 300.
